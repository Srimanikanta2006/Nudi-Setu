# Limitations

- This repository contains official challenge examples and generated bootstrap examples, not real native-speaker collection. They do not establish dialect accuracy.
- Regional words and endings vary by town and speaker; every `needs_native_check` glossary row is a hypothesis.
- Unseen vocabulary, code-mixing, sandhi, context-sensitive agreement and ambiguity can produce incorrect output.
- The chat website uses only local deterministic mappings and rules. It cannot guarantee a correct rewrite for an unseen sentence.
- The pasted AI-generated candidate rows have generic, unsupported source claims and are excluded from conversion and training.
- Havyaka is an experimental extra UI option, separate from the three challenge varieties; its published-word mappings need fluent-speaker review.
- Exact public-source matches are still marked for native review and are not speaker-verified pairs.
- Small and unrepresentative data will make evaluation unstable. Keep test examples out of the glossary and report empty/low-data metrics honestly.
