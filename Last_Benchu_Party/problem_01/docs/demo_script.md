# Demo script (2–3 minutes)

1. Introduce Nudi Setu and the three supported dialects. Explain that the official pipeline is shown above the converter.
2. Select Hubballi-Dharwad and try **ಏನ್ರಿ, ಊಟ ಆತೇನ್ರಿ?** → **ಏನು, ಊಟ ಆಯಿತೇ?**. Open the conversion trace and point out the rule hits.
3. Try Mangaluru **ಎಂತ ಮಾಡ್ತಾ ಇದ್ದೀರಿ?** → **ಏನು ಮಾಡುತ್ತಿದ್ದೀರಿ?**.
4. Try Uttara Kannada **ಹೆಂಗಿದ್ದೀರಿ, ಊಟಕ್ಕೆ ಬರ್ತೀರಾ?** → **ಹೇಗಿದ್ದೀರಿ, ಊಟಕ್ಕೆ ಬರುತ್ತೀರಾ?**.
5. Show batch CSV conversion, then DATA STATUS, glossary confidence labels, and collection/consent kit. Be clear that official examples are not real speaker contributions and bootstrap synthetic data are marked.
