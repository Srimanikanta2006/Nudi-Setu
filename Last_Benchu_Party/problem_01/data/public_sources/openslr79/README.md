# OpenSLR SLR79 Kannada transcript index

These files contain the public Kannada transcript index supplied to the Nudi Setu project. They are **general read-speech transcripts**, not dialect-to-standard pairs.

## Contents

- `03_openslr79_transcript_index_female.tsv` — 2,186 rows
- `03_openslr79_transcript_index_male.tsv` — 2,214 rows

Each TSV row contains an OpenSLR utterance ID and its Kannada transcript. The indexes contain no town or dialect labels. The gender grouping is inherited from the source index; Nudi Setu does not infer or add speaker attributes.

## Permitted project use and limits

The supplied source notes identify SLR79 as CC BY-SA 4.0. Attribute the corpus and keep any redistributed adaptations under the same license. See [OpenSLR SLR79](https://www.openslr.org/79/) and the corpus paper: He et al. (2020), *Open-source Multi-speaker Speech Corpora for Building Gujarati, Kannada, Malayalam, Marathi, Tamil and Telugu Speech Synthesis Systems*, LREC, [ACL Anthology](https://aclanthology.org/2020.lrec-1.800/).

These indexes can support a **general Kannada reference or non-dialect baseline** (for example, checking that the converter leaves textbook-like Kannada largely unchanged). They cannot establish dialect performance, provide dialect labels, count toward the project’s consented speaker collection, or be presented as Nudi Setu-collected contributions. Do not use them as source sentences for synthetic dialect pairs. Audio is not included here; consult the source terms before obtaining or redistributing audio.

Keep this folder separate from `data/dataset.csv`. Track any derived benchmark outputs as external-source results and retain attribution and share-alike terms.
